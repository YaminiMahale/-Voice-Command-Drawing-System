# Voice Command Drawing System

## Project Description
This project allows users to create drawings and designs using voice commands.

## Features
- Voice-controlled shape creation
- Circle, Square, Rectangle, Triangle and many more shapes
- Shape color filling
- Image insertion using voice commands
- Save projects to MongoDB
- Load saved projects
- Delete projects
- Undo/Redo functionality

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
